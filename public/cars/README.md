# Optimized car assets

This directory is reserved for optimized, Draco-compressed GLB files for the future Car Pack. Keep each committed GLB under 8 MB, remove real-world badges/logos from textures, and retain the attribution in `docs/CAR_LICENSES.md` and the in-game credits screen.

Original owner-supplied GLBs belong in the ignored `assets/raw/` directory and must not be committed. The M1 build uses a procedural prototype car and contains no licensed car model.
